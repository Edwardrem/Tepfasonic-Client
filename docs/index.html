Getting started

  1. Press ⌘N to add a host, or type user@host:port in the quick-connect field and press Return to connect without saving.
  2. The first connection shows the server's host-key fingerprint. Compare it with what the server administrator gave you before trusting it.
  3. Double-click a host to open it in a new tab. Split the tab with ⌘D (right) or ⇧⌘D (down).

Jump hosts, proxies and forwarding

Edit a host and choose a jump host under Route; the connection is tunnelled through the bastion's SSH connection, and bastions chain. Proxies (HTTP CONNECT or SOCKS5) sit on a host or a group. The Port Forwarding sidebar (⇧⌘P) holds local, remote and SOCKS5 rules that start with a click or on connect and show live byte counts.

Files

Press ⌥⌘O in a session for the dual-pane SFTP browser. Either pane can show this Mac or any host; drag between them, or from the Finder. Double-click a remote file to open it in its default app; saving uploads it again.

Themes and appearance

Settings → Appearance picks the colour scheme (one scheme, a light and dark pair that follows macOS, or a pair on a schedule), the font and the cursor. The scheme colours the whole app: the sidebar, tabs, status bar, Claude panel, sheets and every window derive their palette and accent from it, and Colour the whole app with the scheme turns that off for the standard macOS materials. Every window also goes light or dark with the scheme in use; choose Follow the system, Always light or Always dark there to decouple them. View → Theme Editor… edits, imports and exports schemes, and hosts and groups can override the scheme and font.

Claude: files in and out

In the Claude panel (⇧⌘A) the paperclip attaches images, PDFs, Word documents and text files to your message; dropping files on the panel does the same. Ask for a report, inventory or runbook "as a PDF" or "as a Word document" and Claude writes it with its create_document tool; the file is saved under Agent/Documents in the app's data folder and appears as a card with Open, Show in Finder and Save As…. HTML, Markdown, text and CSV work the same way.

Serial consoles and cloud imports

File → New Serial Console… saves a /dev/cu.* device with its line settings; it opens in a normal tab with an optional hex view. File → Import From → Cloud Provider lists EC2, DigitalOcean and Azure instances once read-only credentials are saved in Settings → Cloud.

Where things live

Hosts, groups, identities, snippets, forwarding rules, themes and serial profiles: ~/Library/Application Support/Tepfasonic/Tepfasonic.store. Trusted host keys: known_hosts.json in the same folder. Open tabs: workspace.json. Backups: backups/. Open-with copies of remote files: OpenWith/. Private keys, passwords, proxy passwords, the Claude API key and cloud credentials: the macOS Keychain.
