A fix for a Claude chat error that could lock a conversation, and folders as attachments.

### Fixed

- **"`tool_use` ids were found without `tool_result` blocks" no longer breaks a conversation.** When a reply was cut off or interrupted while Claude was calling a tool (the output limit was reached, the connection dropped, or the app quit while a command was running), the saved conversation was left with a tool call that had no answer, and every later message in it failed with this error. Tepfasonic now answers such a call itself, and it repairs conversations saved by earlier versions when they are opened, so a conversation that was stuck works again with nothing to do on your side.
- **Opening another conversation while Claude is replying no longer damages it.** The reply in flight belonged to the conversation you left, but its partial text could be saved into the one you opened, replacing that conversation's history. The reply is now abandoned with the conversation it belongs to.
- **A cut-off tool call is never run.** A call whose input arrived incomplete is answered with an error that tells Claude what happened, instead of being run with half its input, and the chat says that the reply was interrupted.

### New

- **Attach a folder.** The paperclip now accepts folders as well as files, and so does a drop on the panel. The folder's text files (code, configs, logs, Markdown, CSV, Word documents as their text) travel as one attachment with a listing of what is in it; images and PDFs inside the folder come along as attachments of their own.
- **What a folder leaves out, and says so.** Hidden files, dependency and build folders (`node_modules`, `build`, `dist` and the like), symbolic links and anything that looks like a key or credential stay on your Mac, and the attachment lists what was left out and why. A folder is read up to fixed limits (400 KB of text, 128 KB per file, 20 images or PDFs, 2,000 entries), so a large folder gives a partial bundle that says how much it covers.

### For developers

- `AgentTranscript.repaired(_:)` returns a transcript in which every assistant turn with tool calls is answered by the next user turn (missing results added as errors, orphaned and duplicate results dropped, results first). `AgentSession` applies it on load, rewind and send, and both providers apply it when they build a request. Covered in `TranscriptRepairTests`.
- `AgentSession.replace(messages:)` always takes effect: a run in flight is cancelled and detached by a generation number, and the next run waits for it to unwind.
- `AttachmentImporter.importFolder(at:into:)` walks a folder within the limits above and returns the text bundle followed by the images and PDFs. `AgentAttachment.folderFileCount` (optional) marks a bundle; transcripts without it still load. Word documents are extracted from a private temporary copy, so a file name is never passed to `unzip`. Covered in `FolderImportTests`.
- Debug builds take `--qa-attach=<path>` (repeatable) to put files or folders on the composer for screenshots.
