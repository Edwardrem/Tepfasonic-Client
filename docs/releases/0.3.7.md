Copy and edit in the Claude chat, a recording meter for dictation, a new default theme with a family of siblings, and larger, more colourful side panels.

### New

- **Copy a message or the whole chat.** Every message has a copy button under it, and the conversation menu has **Copy Conversation**, which puts the chat on the clipboard as plain text.
- **Edit a message and send it again.** The pencil under your own messages puts the text and its attachments back in the composer. Sending replaces that message and every reply after it; Cancel leaves the chat as it was.
- **You can see that dictation is recording.** While you dictate, the text field shows a red outline, level bars that follow your voice and a running clock. If the microphone delivers no sound, if nothing was recognised, or if the recogniser stops, the composer says so instead of quietly going back to idle.
- **Send while recording.** Pressing Send stops the recording and sends what is in the field.

- **Lagoon, the new default theme, and its family.** Lagoon is the charcoal look with the aqua accent, now a named scheme and the default. Six dark siblings share its canvas and palette and differ only in accent: Meadow (green), Ember (orange), Sunbeam (yellow), Coral (pink), Orchid (purple) and Cobalt (blue). Three light ones do the same on white: Shoreline (the default light scheme), Orchard and Harbor. If you never chose a scheme you get Lagoon; a scheme you chose is kept.

### Changed

- **A larger, more colourful sidebar.** Host, snippet, history and forwarding rows are a size up with bigger icon tiles. Snippets and forwarding rules get their own tiles, group counts take the group's colour, and hosts without a colour label get a slate-blue tile instead of grey.
- **A larger, more colourful Claude panel.** Text, buttons and tool rows are a size up. Icons carry colour in the iOS manner, and each colour means one thing: blue attaches and copies, green is voice, orange edits, indigo runs commands, teal reads, red is a document.
- **Dictation picks a language that works.** A region without its own on-device speech model falls back through your preferred languages to US English rather than hiding the microphone.
- **First-launch instructions are correct for macOS 15 and later.** Unsigned builds are opened with **Open Anyway** under System Settings › Privacy & Security; right-click → Open no longer works there.

### For developers

- `AgentSession.rewind(to:)` drops a message and everything after it; `AgentTranscript.plainText(_:)` renders a transcript for the clipboard. Both are covered in `AgentSessionTests`.
- `AgentPanelController` holds the message being edited (`editing`, `beginEditing`, `cancelEditing`); the rewind happens only once the provider is ready, so a setup error keeps the original message.
- `SpeechDictation` exposes a lock-protected `DictationMeter` written from the audio tap and read by a `TimelineView` leaf that takes no part in hit-testing. The tap is installed from a `nonisolated` helper, and a generation counter discards late results from an earlier recording.
- `TerminalTheme` has an optional `accent` (`#RRGGBB`) that the app chrome uses before deriving one from the ANSI colours; theme JSON without it still loads. `defaultDark` and `defaultLight` are now looked up by id (`builtin:lagoon`, `builtin:shoreline`).
- `Design.Tint` names the icon colours, `Design.chatTextSize` and `Design.sidebarTextSize` the body sizes. Debug builds take `--qa-dictation-demo` and `--qa-agent-edit` for screenshots.
