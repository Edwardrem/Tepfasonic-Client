Talk to Claude: the composer takes dictation, transcribed on your Mac.

### Added

- **Dictate a message to Claude.** A microphone button in the Claude composer turns speech into text. Tap it, speak, and your words stream into the draft, where you edit and send as usual; tap again (or let Claude finalise the utterance) to stop. Transcription runs entirely on your Mac with on-device speech recognition, so the audio never leaves the machine, like everything else in the app. The microphone is hidden when the current language has no on-device model.
- The project site and the README now have a screenshots gallery: the fleet terminal, the Claude panel writing a report, the destructive-command approval, the host editor, identities, the group editor, snippets, the theme editor and light mode.

### For developers

- `SpeechDictation` (`App/Tepfasonic/Agent`) wraps `SFSpeechRecognizer` with `requiresOnDeviceRecognition` and feeds it from an `AVAudioEngine` input tap; the composer owns the text through an `onUpdate` closure, so dictation fills the draft rather than sending on its own. `NSMicrophoneUsageDescription`, `NSSpeechRecognitionUsageDescription` and the `com.apple.security.device.audio-input` entitlement (for the hardened-runtime release build) are set in `project.yml`.
