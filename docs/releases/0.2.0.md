### Fixed

- **The downloaded app did not start.** The 0.1.0 build was ad-hoc signed with the hardened runtime on, and the runtime's library validation (which needs a Team ID) refused the embedded Sparkle framework, so the app died at launch. Unsigned builds now ship without the hardened runtime; Developer ID builds keep it, and the release workflow refuses to publish a build that does not stay up.
- **Hosts could not be added.** The host editor compared the chosen jump host with the host being edited; for a new host both were empty, so the Add Host button stayed disabled whatever was typed. The check now only fires when a host really points at itself, and the editor says beside the buttons what still needs attention (hostname, port, username, identity, proxy fields) instead of leaving Save greyed out silently.

### Added

- **An app icon**: a dark macOS squircle with the shell prompt chevron and a blue waveform, at every size the Dock, Finder, Launchpad and the DMG need.
- **The colour scheme applies to every window.** Settings → Appearance has a new default, "Match the colour scheme": the main window, session windows, Files, the Theme Editor, Identities & Keys, Settings, sheets and menus all go light or dark with the terminal scheme in use. "Follow the system", "Always light" and "Always dark" now apply to every window too, not just the main one, and "Follow the system" tracks the macOS setting itself rather than the app's own look.

### Changed

- Release notes are built from `docs/releases/<version>.md` plus the commits since the previous tag.
