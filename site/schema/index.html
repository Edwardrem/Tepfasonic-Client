The .tepfa file format

A .tepfa file is JSON. Plain files hold the document directly; encrypted files (the default) hold an envelope whose ciphertext decrypts to the same document. Every record carries a stable UUID, so importing the same file twice updates records instead of duplicating them.

Envelope (encrypted)

{
  "format": "tepfa",
  "version": 1,
  "kdf": { "name": "argon2id", "salt": "base64", "memoryKiB": 65536, "iterations": 3, "parallelism": 1 },
  "cipher": "chacha20-poly1305",
  "nonce": "base64 (12 bytes)",
  "ciphertext": "base64 (ciphertext || 16-byte tag)"
}

The key is Argon2id(passphrase, salt) with a 32-byte output; the plaintext is the document below, UTF-8 JSON.

Document

{
  "format": "tepfa",
  "schemaVersion": 1,
  "exportedAt": "2026-11-03T10:00:00Z",
  "appVersion": "0.1.0",
  "groups": [], "hosts": [], "identities": [],
  "snippetFolders": [], "snippets": [],
  "portForwards": [], "themes": [], "serialProfiles": [],
  "knownHosts": [],
  "secrets": { "identities": {}, "proxyPasswords": {} }   // encrypted files only
}

Arrays may be omitted; readers treat a missing array as empty. Fields added in later releases are optional so older files still import.

Records

ArrayFields
groupsid, name, sortOrder, colorLabel, defaultIdentityID, defaultJumpHostID, proxy {kind, host, port, username}, themeID, fontName, fontSize
hostsid, name, hostname, port, username, authMethod (password | privateKey), tags, notes, sortOrder, colorLabel, autoReconnect, groupID, identityID, defaultSnippetID, shellIntegration, agentPermission (read-only | ask | allowlist), agentAllowlist, jumpHostID, inheritsGroupJumpHost, proxy, inheritsGroupProxy, themeID, fontName, fontSize, backgroundTint, watermark
identitiesid, name, username, credentialKind (password | keyFile | keychainKey), privateKeyPath, publicKey, keyType, fingerprint
snippetFoldersid, name, sortOrder
snippetsid, name, command, tags, notes, sortOrder, folderID
portForwardsid, hostID, kind (local | remote | dynamic), bindAddress, bindPort, targetHost, targetPort, autoStart, name, sortOrder
themesid, name, source, scheme (a theme document, see below)
serialProfilesid, name, devicePath, baudRate, dataBits, parity (none | even | odd), stopBits, flowControl (none | hardware | software), sendLineEnding (cr | lf | crlf), convertIncomingLF, localEcho, hexView, colorLabel, sortOrder
knownHostshost, port, keyType, publicKey, fingerprintSHA256
secrets.identitieskeyed by identity id: password, privateKey (OpenSSH text), passphrase
secrets.proxyPasswordskeyed by the owning host or group id

Theme document

The same JSON the Theme Editor exports and the gallery serves. Colours are #RRGGBB; ansi holds the 16 ANSI colours (normal then bright).

{
  "format": "tepfasonic-theme/1",
  "id": "uuid",
  "name": "Dracula",
  "foreground": "#F8F8F2", "background": "#282A36",
  "bold": null, "cursor": "#F8F8F2", "cursorText": "#282A36",
  "selection": "#44475A", "selectionText": null,
  "ansi": ["#21222C", "#FF5555", "#50FA7B", "#F1FA8C", "#BD93F9", "#FF79C6", "#8BE9FD", "#F8F8F2",
           "#6272A4", "#FF6E6E", "#69FF94", "#FFFFA5", "#D6ACFF", "#FF92DF", "#A4FFFF", "#FFFFFF"],
  "isDark": true
}

Install links take the form tepfasonic://theme?url=https://…/scheme.json; the app fetches the file, shows a preview and asks before saving it.
