Install

  1. Open the .dmg and drag Tepfasonic to Applications.
  2. Builds are not yet signed with an Apple Developer ID, so macOS blocks the first launch. Open the app once and dismiss the warning, then go to System Settings › Privacy & Security, scroll to Security and click Open Anyway (right-click → Open no longer works on macOS 15 and later). Or run 
    xattr -dr com.apple.quarantine /Applications/Tepfasonic.app
    Once Developer ID signing is in place this step goes away and updates install in place.
  3. Launch it, press ⌘N to add a host or type user@host in the quick-connect field.

Homebrew

brew tap edwardrem/tepfasonic
brew install --cask tepfasonic

The tap repository (Edwardrem/homebrew-tepfasonic) is not published yet, so use the DMG for now; the release workflow bumps the cask automatically once the tap and its token exist.

Verify the download

Every release ships a SHA256SUMS file. Compare it with the image you downloaded:

shasum -a 256 ~/Downloads/Tepfasonic-*.dmg

Updates

The app checks this site's appcast.xml once a day (Settings → Updates). Unsigned builds offer the download; signed builds update in place through Sparkle. Turn on the beta channel to follow pre-releases.

Build it yourself

git clone https://github.com/Edwardrem/Tepfasonic-Client.git
cd Tepfasonic-Client
brew install xcodegen && xcodegen generate
xcodebuild -project Tepfasonic.xcodeproj -scheme Tepfasonic -configuration Release \
  -skipPackagePluginValidation -skipMacroValidation build
